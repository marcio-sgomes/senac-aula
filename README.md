# The Cozy Bean

Landing page de uma cafeteria fictícia, **The Cozy Bean**, feita em aula no Senac.

> 📦 **Projeto de estudo** — não recebe mais atualizações.

## Contexto

Projeto de aula do Senac (junho de 2026). A página tem menu fixo, contadores animados, galeria de fotos, perguntas frequentes (FAQ) e links para redes sociais.

## Tecnologias

- **HTML5 e CSS3** — estrutura e estilo (`cozy-bean/css/style.css`).
- **Bootstrap 5.3 e Bootstrap Icons** (via CDN) — grid, navbar responsiva e ícones.
- **Google Fonts** (Playfair Display e Montserrat) — tipografia.
- **JavaScript** — contadores animados (`cozy-bean/js/script.js`).

## Como abrir

1. Clone o repositório.
2. Abra `cozy-bean/index.html` no navegador (ou use a extensão Live Server do VS Code).
3. É preciso estar conectado à internet para carregar o Bootstrap e as fontes.

## Estrutura

- `cozy-bean/index.html` — a página.
- `cozy-bean/css/` — estilos.
- `cozy-bean/js/` — scripts.
- `cozy-bean/img/` — fundos e fotos da galeria.
